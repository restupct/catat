Hanya di browser ini. Data tersimpan di browser dan perangkat ini, tidak otomatis dicadangkan, dan dapat hilang jika data situs dihapus. Ekspor secara berkala untuk menyimpan salinan.

Data tidak otomatis tersedia di perangkat, browser, atau alamat situs lain. Penyimpanan browser tidak diklaim terenkripsi atau sepenuhnya aman. File ekspor berisi data pengeluaran pribadi; simpan dengan hati-hati.

Tidak ada akun, backend, pelacakan, atau sinkronisasi. Koneksi pihak ketiga hanya untuk aset Tailwind CSS dan Font Awesome. Cache HTTP mengikuti browser; aplikasi belum menjamin penggunaan offline. Tailwind Play CDN digunakan untuk kemudahan prototipe, bukan rekomendasi produksi Tailwind.
